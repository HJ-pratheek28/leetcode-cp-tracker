# Solution Review Rubric

Use this before marking a problem independent or mastered.

## Modeling
- [ ] Exact task and constraints identified
- [ ] Brute-force baseline stated
- [ ] Representation matches the problem
- [ ] Worst-case complexity fits

## Correctness
- [ ] Invariant, state, or key property is explicit
- [ ] Initialization is valid
- [ ] Each step preserves correctness
- [ ] Algorithm terminates
- [ ] Termination implies the required answer
- [ ] Duplicates, boundaries, and impossible cases considered

## Complexity
- [ ] Time complexity justified
- [ ] Auxiliary space includes data structures and recursion
- [ ] Assumptions stated (e.g. expected hash lookup)

## Implementation
- [ ] Empty / smallest inputs
- [ ] Duplicates and repeated values where relevant
- [ ] Negative / zero / maximum values where relevant
- [ ] Index boundaries and off-by-one cases
- [ ] Integer overflow and sentinels
- [ ] Iterator, reference, and pointer validity
- [ ] C++ container behavior understood

## Learning
- [ ] Can explain why the pattern applies
- [ ] Can reconstruct without saved code
- [ ] Recorded the first mistake and the correction
- [ ] Scheduled a review
- [ ] Can describe a variation that changes the algorithm

## Readiness levels
- **Attempted:** reasoning or implementation incomplete; major hints needed.
- **Independent:** derived and implemented without solution-level help.
- **Re-solved:** reconstructed after a meaningful delay.
- **Mastered:** repeated independent recall, correctness explanation, complexity analysis, and pattern transfer.

A passed submission is evidence—not the entire evaluation.
