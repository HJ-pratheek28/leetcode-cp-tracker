# How to maintain this tracker

This is a personal learning log, so keep notes concise and honest.

## Add a problem

1. Choose the pattern that best explains the main insight.
2. Add a row to that pattern's Markdown table.
3. Link directly to the problem statement.
4. Record difficulty, status, the core observation, complexity, and any mistake worth remembering.
5. Fill review dates after re-solving.

## When to mark solved

- **⬜ Not started:** not attempted yet.
- **🟡 Attempted / needs review:** needed substantial hints, solution, or still cannot explain it.
- **✅ Solved independently:** derived and implemented the approach without solution-level help.
- **🔁 Re-solved after review:** solved again later without relying on stored code.

## Useful note template

- **Trigger:** What clue suggested this pattern?
- **Invariant/state:** What remains true during the algorithm?
- **Complexity:** Time and auxiliary space.
- **Mistake:** What would I do differently next time?

Prefer explaining the insight over pasting a full solution.
